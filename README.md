Deployment

Hosted via GitHub Pages, served directly from the main branch root. Any push to index.html on main updates the live site within a minute or two.

Accessibility & performance notes
Respects prefers-reduced-motion — all animations disable for users who request it
Visible keyboard focus states throughout
Fully responsive down to mobile, with a collapsible nav menu
No external font/script dependencies — everything (including the profile photo) is self-contained in one file for fast, reliable loading
